# bookstr

AGPL-3.0 EPUB reader: native Android (Kotlin/Compose) + web (React/Vite). Books come from an HTTPS catalog identified by **SHA-256 of the EPUB file**. Optional Nostr progress sync. Optional Android lock-screen reading.

## Layout

- `android/` — `app.bookstr` (Gradle 8.11.1, AGP 8.7.3, Kotlin 2.0.21, compile/target SDK 35, minSdk 27)
- `web/` — Vite + React + TypeScript + epub.js + nostr-tools
- `catalog/` — `catalog.json` + seed/hash scripts (EPUB binaries gitignored)
- `scripts/bootstrap-android-toolchain.sh` — JDK 17 + Android SDK 35 on a build VM
- `openspec/` — spec-driven change tracking

## Android reader

Uses a **WebView + bundled epub.js** (distraction-free chrome, volume keys, paper/night). **Readium is not a dependency yet.**

Lock-screen reading: toggle in Settings or the in-reader overlay. Uses `setShowWhenLocked` / `setInheritShowWhenLocked` and does **not** dismiss the keyguard. Some OEMs (especially Xiaomi/MIUI) need an extra “display over lock screen” app permission.

## Host your catalog

Serve static files over HTTPS:

```text
https://books.example.com/catalog.json
https://books.example.com/books/<sha256>.epub
```

`catalog.json` `id` must equal the lowercase hex SHA-256 of that EPUB. Clients verify on download.

CORS for the web app (adjust origin as needed):

```nginx
location / {
  add_header Access-Control-Allow-Origin *;
  add_header Access-Control-Allow-Methods "GET, OPTIONS";
}
```

Seed / hash locally (binaries stay out of git):

```bash
cd catalog
./scripts/fetch-seeds.sh   # optional public CC/PD seeds
# or drop private EPUBs into staging/
./scripts/hash-epubs.sh
# then update catalog.json ids to match
```

## Web

```bash
cd web
npm ci
npm run dev      # catalog default: /catalog/catalog.json
npm run build
```

### GitHub Pages

The web app deploys from `.github/workflows/deploy-web.yml` on pushes to `main` that touch `web/` (or via **Actions → Deploy web to GitHub Pages → Run workflow**).

1. Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. After the first green run: **https://guaka.github.io/bookstr/**
3. Point Settings → catalog URL at a real HTTPS catalog (EPUB binaries are not in git). The bundled `public/catalog/catalog.json` is metadata-only unless you host books elsewhere.

**Custom domain later (`bookstr.guaka.org`):** add a DNS CNAME to `guaka.github.io`, set the domain under Pages, change the workflow `BASE_PATH` to `/`, and optionally commit `web/public/CNAME` with `bookstr.guaka.org`.

## Android

```bash
# on ebook-dev / a build host:
sudo ./scripts/bootstrap-android-toolchain.sh
cd android
./gradlew assembleDebug
```

`local.properties` with `sdk.dir=...` is generated by the bootstrap script (gitignored).

## Nostr

Opt-in: paste `nsec` (Android: EncryptedSharedPreferences; web: session settings / NIP-07 when available). Progress events are kind `30078` with `d=app.bookstr.progress.<sha256>`. Use disposable keys for testing; never commit `*.nsec`.
