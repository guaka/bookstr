# Electron catalog sources

Electron currently searches Libcat, using the connected Nostr signer and
encrypted NIP-17 requests. Its source list contains no public providers or
custom OPDS feeds.

The other catalog adapters remain available to the web and mobile clients.
Their Electron integration is deferred: all.books.party, Unglue.it, Project
Gutenberg, OAPEN, Open Textbook Library, DOAB, Global Digital Library, Internet
Archive, and custom OPDS feeds are not active Electron sources yet.
